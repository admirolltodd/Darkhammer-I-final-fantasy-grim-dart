# Music

Drop OGG (preferred), MP3, or WAV files here. The engine picks them up by
filename — no code changes needed. Until real files exist, the game falls
back to generated chiptone loops.

| Filename            | Plays during            |
|---------------------|--------------------------|
| title.ogg           | Title screen             |
| worldmap.ogg        | Overworld                |
| town.ogg            | Hive cities              |
| dungeon.ogg         | Dungeons                 |
| battle.ogg          | Random battles           |
| battle_2.ogg, battle_3.ogg, ... | More battle tracks — rotates each fight |
| boss.ogg            | Boss battles             |
| victory.ogg         | Victory fanfare          |
| gameover.ogg        | Game over                |

Good sources for free (CC0 / CC-BY) JRPG battle music:
- opengameart.org (filter: Music, CC0)
- incompetech.com (CC-BY, Kevin MacLeod)
